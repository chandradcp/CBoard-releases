# CalBoard Data Deletion

_Last updated: 24 August 2026_

CalBoard does not create an online account and does not store your keyboard data on CalBoard servers. Your settings, personal dictionary, clipboard history, Smart Reply context, saved logins, payment cards, personal details, and one-time codes are stored locally on your Android device.

## Delete selected data

You can remove individual categories from within CalBoard:

- Delete individual clipboard items or clear clipboard history in **Settings → Clipboard**.
- Clear learned words in **Settings → Dictionary**.
- Delete saved logins, payment cards, and personal details in **Settings → Autofill & OTP**.
- Disable Smart Reply context sources in **Settings → Smart Reply**. Smart Reply context is temporary and is discarded when the session ends.
- Revoke notification access through Android system settings.

## Delete all CalBoard data

To delete all locally stored CalBoard data, either:

1. Open Android **Settings → Apps → CalBoard → Storage & cache → Clear storage**, or
2. Uninstall CalBoard.

This removes CalBoard's locally stored settings and user data from that device. Because CalBoard has no user account or cloud storage, there is no separate server-side account or data-deletion request to process.
